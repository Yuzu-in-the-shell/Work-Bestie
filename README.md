# 🐾 上班搭子 Work Bestie

一个纯前端的像素风网页小应用，让一只可爱的猫咪陪你上班：

- 🐱 会眨眼、摇尾巴的像素猫咪（canvas 绘制，无需图片素材）
- 💬 和猫咪聊两句：内置一批猫咪语录兜底，也可以在设置里填入你自己的 OpenAI API Key，接入真正的 AI 对话
- 💰 今日已赚到的钱会随时间实时增长
- ⏰📅 今日 / 本周工作进度条

## 使用方法

不需要安装任何依赖，直接用浏览器打开 `index.html` 即可，或者部署到 GitHub Pages / 任意静态托管服务：

```bash
python3 -m http.server 8080
# 然后打开 http://localhost:8080
```

首次打开后点右上角「⚙️ 设置」，填写你的月薪、上下班时间、每周工作天数，以及猫咪的名字。

## 关于 AI 聊天

这是一个纯静态网页，没有后端服务器。如果你想让猫咪用 AI 回复（而不是内置语录），需要在设置里填入你自己的 **OpenAI API Key**：

- Key 只保存在你浏览器的 `localStorage` 里，不会上传到除 OpenAI 官方接口以外的任何地方
- 网页会直接从浏览器调用 `https://api.openai.com/v1/chat/completions`
- 不填 Key 也完全可用，会使用内置的猫咪语录库

## 数据存储

所有设置和聊天记录都只保存在你自己浏览器的 localStorage 中，换设备/换浏览器不会同步。
